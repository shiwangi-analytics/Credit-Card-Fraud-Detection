# 💳 Credit Card Fraud Detection Using Machine Learning

## 📌 Project Overview

Credit Card Fraud Detection is a Machine Learning project designed to identify whether a credit card transaction is **Genuine or Fraudulent**.

With the increasing use of online transactions, credit card fraud has become a major concern. This project uses Machine Learning techniques to analyze transaction data and predict potentially fraudulent transactions.

## 🎯 Project Objectives

- Detect fraudulent credit card transactions.
- Classify transactions as Genuine or Fraudulent.
- Reduce the risk of financial fraud.
- Provide a simple and user-friendly interface for predictions.

## ✨ Features

- Upload transaction data.
- Supports CSV/PDF input (as implemented in the application).
- Predict whether a transaction is genuine or fraudulent.
- Simple and interactive user interface.
- Displays prediction results.

## 🛠️ Technologies Used

- Python
- Machine Learning
- Pandas
- NumPy
- Scikit-learn
- Streamlit (if used in the application)

## ⚙️ How It Works

1. Upload the transaction data.
2. The system processes the uploaded data.
3. The trained Machine Learning model analyzes the transaction.
4. Click on the Predict button.
5. The system displays whether the transaction is Genuine or Fraudulent.
